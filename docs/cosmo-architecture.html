A VS Code agent that turns a prompt, a PRD, or an existing Figma file into three reviewable deliverables — a Figma design built from real components, a WCAG 2.2 AA + Responsible-AI compliance audit, and production-ready React / TypeScript — with a human review gate at every phase.

What Cosmo produces

Three deliverables, one flow

Cosmo runs as a sequence of gated phases. Each phase produces one artifact and stops for your approval before the next begins — nothing advances silently.

1 · Figma designFrames assembled from real design-system components, bound tokens, and layout patterns — authored straight into your file.
2 · Compliance auditA severity-graded report across accessibility, content design, RAI, design language, and component usage.
3 · React + TypeScriptPer-component code mapped to verified component APIs, following your project's React conventions.
Core principle — never from memory Cosmo only uses components, props, tokens, and keys it can read from a live source. If it can't verify something, it says so and stops — rather than inventing a component, prop, or token.

The design track

The Figma plugin pipeline

The Dev Mode MCP is read-only for canvas content, and the Figma REST API has no endpoint that creates frames. The only way to write a design programmatically is the Figma Plugin API — so Cosmo reads and writes real components through three small, auditable plugins.

① key-extractorruns in the published library → exports every name → key
→
② key-testruns in the target file → confirms keys are published & enabled
↓
③ build pluginassembles frames from real instances

How the build plugin places a real component

const comp = await figma.importComponentByKeyAsync(key);
const instance = comp.createInstance();
frame.appendChild(instance);
instance.layoutSizingHorizontal = "FILL";   // size top-down, after append
Fallback, clearly labelled When a component is genuinely unpublished or missing, the build plugin emits a styled primitive and labels it as such — it never fabricates a key.
The workflow

Four phases, with gates

A pattern-match check (Phase 0) can shortcut well-known UX patterns. Otherwise the request flows through four gated phases — each one waits for your approved.

01

Intake

Turn the prompt / PRD / Figma URL into a structured spec: purpose, users, screens, data, edge cases, fidelity.

02

Design

Plan a verified component inventory, then generate a build plugin that writes the frames into Figma.

03

Audit

Re-read the frames and produce a severity-graded report across five compliance domains.

04

Code

Map each frame to a component tree and emit React/TypeScript per component, mapped to verified APIs.

Setup

Wiring the MCP servers

Cosmo uses two HTTP MCP servers, registered in your workspace at .vscode/mcp.json.

// .vscode/mcp.json
{
  "servers": {
    "figma-desktop": { "type": "http", "url": "http://127.0.0.1:3845/mcp" },
    "component-docs": { "type": "http", "url": "https://<your-docs-mcp-host>/mcp/server/" }
  }
}
ServerRoleNotes
figma-desktopReads the canvas; the target the build plugin writes intoFigma desktop → Preferences → Enable Dev Mode MCP Server (runs at 127.0.0.1:3845).
component-docsComponent props / tokens, and the source of the generated codeHTTP server; may be internal. Start it in MCP: List Servers.
The most common gotcha The server name in mcp.json must match the name in the agent's tools allowlist. A mismatch is the #1 reason “the MCP is running but the agent can't see it.”
Quality

Standards baked in, not bolted on

Compliance is applied at design time and code-generation time — not just at the audit step.

WCAG 2.2 AAContrast, focus order, keyboard operability, accessible names, live regions, target size — annotated in Figma and enforced in code.
Responsible AIAI identity marks, disclaimers, feedback affordances, and consent-first behaviour on any AI output.
Content designSentence case, plain language, and the error formula — what happened + why + how to fix.
Design tokensSpacing, colour, typography, elevation, and radius bound to tokens — never hardcoded hex or px.
